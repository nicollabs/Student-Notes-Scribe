**Student Notes Scribe**

A simple, self-contained HTML tool for generating tiered-support blurbs for student notes. Select the supports and strategies used across Tier 1, Tier 2 and Tier 3 (Engagement, Learning and Wellbeing), plus optional Teacher Aide and Collaborative Teaching support, choose a frequency for each, and generate a ready-to-use written summary.

**Features**
Tiered strategy library covering Engagement, Learning and Wellbeing across Tier 1 (Universal), Tier 2 (Targeted) and Tier 3 (Intensive) supports
Optional "Learning Partners" section for Teacher Aide Support and Collaborative Teaching Support strategies
Search to quickly find a strategy
Frequency selector for each chosen strategy (e.g. "Once per lesson", "Once per week", "As needed")
Blurbs organised by domain, then grouped by frequency from most to least intensive, to support NCCD moderation
Editable output box with a character count warning
Copy to clipboard, with a prompt to clear the form for the next student
Warning before leaving the page if a generated blurb hasn't been copied
"Edit interface" mode to hide strategies you don't use, reorder them, and add your own custom strategy cards
Export and import of interface settings, to move your layout between devices or share it with colleagues
**Usage**
Open the tool on GitHub Pages. Alternatively, download index.html and open it in any modern web browser; no build step, server or installation is required.
Enter a student name (optional; leave blank to use "the student").
Select the relevant strategies and choose a frequency for each.
Click Generate to produce a blurb, then edit or copy it as needed.

The hosted version is recommended, as it always has the latest updates. Downloaded copies need to be re-downloaded to receive fixes and changes.

**Privacy and security**
No AI. Blurbs are generated by a rules-based system; nothing is sent to any AI model.
No student data is stored or transmitted. Student names, selections and blurbs exist only in the open page and disappear when it is refreshed or closed.
No network requests. A Content Security Policy blocks the page from connecting to any server, loading external resources or submitting data. As with any website, GitHub's servers see the basic request when the page is first loaded.
No tracking, analytics or cookies.
No third-party code. The tool has no libraries or external dependencies.
Interface preferences only. Hidden strategies, ordering and custom cards are saved in your browser's localStorage, on that device only. Avoid putting student names in custom cards, as anyone using the same browser can see them.
Validated settings. Saved and imported settings are checked against a strict whitelist before use, and anything malformed is discarded. Exported settings files contain your layout and custom cards only, never student information.
Reset at any time. Preferences can be cleared using Reset in Edit interface mode.
